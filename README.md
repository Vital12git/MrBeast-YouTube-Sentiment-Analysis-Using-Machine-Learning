# MrBeast YouTube Sentiment Analysis

## Project Overview

MrBeast YouTube Sentiment Analysis is a Machine Learning and Natural Language Processing (NLP) project that analyzes comments posted on MrBeast's YouTube videos.
The project evaluates audience reactions, identifies emotional tones, and classifies comments into different sentiment categories such as **Positive, Negative, and Neutral**.
By processing YouTube comments, this project helps understand audience opinions, engagement patterns, and overall viewer satisfaction.

## Objectives
- Collect comments from MrBeast's YouTube videos.
- Preprocess and clean text data.
- Perform sentiment analysis using NLP techniques.
- Classify comments into Positive, Negative, and Neutral sentiments.
- Visualize audience opinions through graphs and charts.
- Understand audience engagement and reactions.

## Technologies Used
  **Programming Language: Python
- **Libraries: Pandas, NumPy, Matplotlib, Seaborn
- **NLP: NLTK / TextBlob
- **Machine Learning: Scikit-learn
- **Development Environment: Jupyter Notebook / Google Colab

##  Project Workflow
1. **Data Collection:Collect YouTube comments from MrBeast videos.
2. **Data Preprocessing: Remove URLs, special characters, punctuation, and unnecessary words.
3. **Text Cleaning:Convert text into lowercase and remove stopwords.
4. **Feature Extraction: Convert text into numerical features using TF-IDF.
5. **Model Training: Train a machine learning model to classify sentiments.
6. **Sentiment Prediction: Predict whether comments are Positive, Negative, or Neutral.
7. **Visualization: Display sentiment distribution using charts and graphs.

##  Sentiment Categories

| Sentiment | Description |
| Positive | Comments expressing happiness, appreciation, or support. |
| Negative | Comments expressing criticism, dissatisfaction, or disappointment. |
| Neutral | Comments expressing general information or no clear emotional opinion. |

## Expected Results

- Graphical representation of audience sentiment.
- Insights into audience reactions and opinions.
